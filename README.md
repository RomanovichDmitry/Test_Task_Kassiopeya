# Карточка товара Teaboom.ru — тестовое задание

Вёрстка верхней части карточки товара «Ананасовый улун» для интернет-магазина [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

## Что сделано

- изображение, название, категория, фасовка, артикул, цены, кнопка «В корзину», описание;
- переключение фасовок обновляет цену, старую цену, артикул и активное состояние;
- hover/active для кнопки «В корзину»;
- адаптив под 1440 / 768 / 375 px;
- HTML5, SCSS → CSS, vanilla JS, Flexbox / Grid;
- стилистика близка к Teaboom.ru (Open Sans, кремовый фон, салатовая кнопка, красная цена).

## Структура

```
├── index.html
├── css/style.css          # собранные стили (подключены в HTML)
├── scss/
│   ├── _variables.scss
│   └── style.scss         # исходники SCSS
├── js/main.js
├── assets/images/
└── README.md
```

## Запуск

Откройте `index.html` в браузере — сервер не нужен.

Либо локальный сервер:

```bash
npx serve .
```

## Пересборка SCSS (опционально)

Если установлен Sass:

```bash
npx sass scss/style.scss css/style.css
```
